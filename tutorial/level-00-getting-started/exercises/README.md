# Level 00 Exercises — Getting Started with C#

## Instructions

Complete the exercises in order. Write the code yourself before checking the solutions.

### Exercise 01 — Hello World

1. Display `Hello, World!`.
2. Display your name on a second line.
3. Add a comment explaining what your program does.

### Exercise 02 — Syntax

1. Identify `using`, `namespace`, `class`, and `Main()` in the traditional example.
2. Write a program that displays two messages.
3. Explain why a missing semicolon can cause an error.
4. Explain why `Console` and `console` are different.

### Exercise 03 — Output

Write a program that displays:

```text
DAILY EXPENSES
Breakfast: 100
Transport: 80
Lunch: 150
Total: 330
```

Requirements:

- Use `Console.WriteLine()` for the headings and descriptions.
- Calculate the total using `100 + 80 + 150`.
- Use `Console.Write()` at least once.

### Exercise 04 — Comments

1. Write a single-line comment.
2. Write a multi-line comment.
3. Add a comment at the end of an output statement.
4. Comment out an output statement and explain why it no longer executes.

## Completion Rule

Do not mark an exercise complete merely because the code runs. You must also be able to explain the code in your own words.
