Welcome to **Level 01 of the C# Learning Project**.

This level introduces the fundamental programming concepts required to write C# applications. It focuses on storing data, understanding data types, performing calculations, handling user input, and working with text.

The goal is to develop a strong programming foundation through explanations, practical examples, exercises, and mini-projects.

---

## Learning Objectives

By the end of this level, you should be able to:

- Declare, initialize, and update variables.
- Understand and use common C# data types.
- Convert values between different data types.
- Receive and process user input.
- Perform calculations using operators.
- Apply built-in mathematical methods.
- Manipulate and format strings.
- Understand Boolean values and expressions.
- Build a simple calculator using C#.

## Learning Structure

Each topic follows the same learning approach:

1. **Concepts** — Understand the meaning of the topic.
2. **Syntax** — Learn how to write it in C#.
3. **Examples** — Study practical code with comments.
4. **Applications** — Explore real-world use cases.
5. **Exercises** — Solve independent programming challenges.
6. **Solutions** — Compare your work with correct implementations.
7. **Assessment** — Test your understanding before proceeding.

## Mini-Project: Simple Calculator

<details>
<summary><strong>Project Overview</strong></summary>

Build a console-based calculator using the C# fundamentals learned in this level.

### Requirements

The calculator should:

- Accept two numbers from the user.
- Support addition.
- Support subtraction.
- Support multiplication.
- Support division.
- Display the calculated result.

### Concepts Applied

- Variables
- Data types
- User input
- Type casting
- Operators
- Mathematical operations
- Output

### Expected Example

```text
========================
     SIMPLE CALCULATOR
========================

Enter first number: 20
Enter second number: 5

Addition:       25
Subtraction:    15
Multiplication: 100
Division:       4
```

</details>
