# Exercises — C# Fundamentals

## How to Use These Exercises

These exercises are designed to push your understanding beyond surface-level syntax. Each file contains questions that progress from foundational knowledge to engineering-level reasoning. Work through them in order, and for each question, write the code and explain your reasoning before checking any solutions.

**Philosophy:** A "pro engineer" doesn't just know syntax — they understand *why* things work the way they do, can predict behavior in edge cases, and can make deliberate design choices. These questions are written to develop that mindset.

## Methodology

1. **Read the question carefully.** Identify what concept is being tested.
2. **Write the code first.** Don't look at solutions.
3. **Test it.** Run the program with different inputs.
4. **Explain it.** Be able to articulate *why* your solution works.
5. **Reflect.** Consider alternative approaches and their trade-offs.
